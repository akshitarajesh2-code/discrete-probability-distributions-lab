Probability Mass Function (PMF)

Exact Successes
P(X = k) = C(n,k) · pk · (1-p)n-k
P(X = 7) = 0.1844
Meaning: The probability of obtaining exactly 7 successes in 20 trials with success probability 0.35 is 0.1844 (18.44%).

Cumulative & Complementary CDF

Cumulative
Cumulative P(X ≤ 7): 0.6010
Complement P(X > 7) = 1 - P(X ≤ k): 0.3990

Explanation: P(X ≤ k) means the probability of getting k or fewer successes.

In this setup, P(X ≤ 7) is 0.6010, while P(X > 7) is 0.3990.

AIML Lab Context:

Poisson models counts of rare, independent events: requests hitting a server per second, defects per batch, or clicks per minute. In anomaly detection, an observed count with a very small tail probability $P(X > k)$ is flagged as unusual.

AIML Lab Context:

Geometric models waiting time until the first success: retries until a network request succeeds, episodes until an RL agent first reaches the goal, or samples until a rare class appears. It is memoryless: $P(X > m + n \mid X > m) = P(X > n)$.
